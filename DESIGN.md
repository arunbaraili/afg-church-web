# AFG Church design

Gathering hall: white, near-black, and church blue, and photographs of the real church community. The supplied navy-and-gold seal identifies the church at the masthead, footer, and browser tab. An SVG clip preserves the original seal and omits white outside the rim.

## Tokens

| Role | Default |
| --- | --- |
| Page | `#ffffff` |
| Alternate surface | `#edf2f9` |
| Text and primary actions | `#111827` |
| Accent and focus | `#174c9c` |
| Form surface | `#ffffff` |
| Display type | Fraunces |
| Body type | DM Sans |
| Maximum content width | 1320px |

Branding & layout in Decap can override the four primary colors, logo, navigation, section order and visibility. Build validation guards text contrast. Keep the visitor path clear; Sunday time and the visit action belong near the top.

The homepage uses the original muted looping church video, with a still poster for reduced motion or blocked autoplay, visible form labels and status, keyboard access, and a reduced-motion fallback. The Scripture emphasis is the only scroll-driven effect.
