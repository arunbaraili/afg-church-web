# AFG Church Web Platform

A responsive, dynamic web application designed and built from the ground up. This platform features a custom-styled modern frontend integrated with a working Content Management System (CMS) pipeline for seamless data rendering.

## 🚀 Live Demo
[afgchurch.com](https://afgchurch.com)

## 🛠️ Tech Stack & Architecture
  *Frontend: Semantic HTML5, Custom Architecture CSS (CSS Variables, Flexbox, Grid), Vanilla JavaScript
  
  *Data & Configuration: JSON (Structured data management), YAML/YML (CMS configuration pipelines)
  
  *Documentation: Markdown

## ✨ Key Features
  *Custom CMS Integration: Dynamic data syncing to handle layout elements like cards, profiles, and interactive             elements cleanly.
  
  *Fully Responsive UI: Fluid breakpoints allowing seamless viewing from massive desktop resolutions down to small           mobile viewports.
  
  *Interactive UI Enhancements: Custom JavaScript-driven components, modal dialog viewports for detailed biographies,       and optimized image container scales.

  *Modern CSS Framework Foundations: Clean utility tracking utilizing root variables for consistent theme and                typography deployment.
