# AFGN Church

[AFGN Church](https://afgchurch.com/) is the website for Assembly Faith Gospel Nepali Church in Nashville. It shares Sunday service times and directions, introduces the pastors and leaders, and features mission stories, photo galleries, and a contact form.

The site uses a white, near-black, and blue palette, with church photography, the AFGN seal, and a video background on the homepage. The layout adapts to phones and desktops.

**Tech stack:** Astro, TypeScript, and CSS for the site; Decap CMS for content editing; Netlify for hosting; and Formspree for the contact form.
